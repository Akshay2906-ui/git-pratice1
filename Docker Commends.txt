# Docker Commends

1.      docker run - run a container from an image
 
2.     docker pull - pull an image from a registry
 
3.     docker push - push an image to a registry
 
4.     docker build - build an image from a Docker file
 
5.     docker ps - list running containers
 
6.     docker stop - stop a running container
 
7.      docker start - start a stopped container
 
8.     docker restart - restart a container
 
9.     docker logs - show the logs of a container
 
10.   docker exec - execute a command inside a running container
 
11. docker images - list available images
 
12.    docker rm - remove a container
 
13.    docker rmi - remove an image
 
14.    docker inspect - show information about a container
 
15.    docker network create - create a network for containers to communicate
 
16.    docker network connect - connect a container to a network

17. docker network disconnect - disconnect a container from a network
 
18.     docker port - show the mapped ports of a container
 
19.     docker cp - copy files between a container and the host
 
20.     docker commit - create a new image from a container's change       
 
21.      docker export - export the contents of a container as a tar archive
 
22.      docker import - create a new image from a tar archive

23.      docker load - load an image from a tar archive
 
24.      docker top - show the processes running inside a container
 
25.      docker stats - show resource usage statistics of containers
 
26.      docker diff - show the changes made to a container's filesystem
 
27.       docker events - show the events generated by Docker

28.       docker history - show the history of an image
 
29.        docker pause - pause a running container
 
30.        docker unpause - unpause a paused container
 
31.         docker kill - send a signal to a container to stop it abruptly
 
32.         docker wait - wait for a container to exit and return its exit code
 
33.         docker attach - attach to a running container's console
 
34.         docker buildx - build and push multi-platform images
 
35.        docker compose - manage multi-container applications with Docker Compose
 
36.       docker swarm - create and manage a cluster of Docker nodes
 
37.        docker volume create - create a named volume for persistent data storage
 
38.        docker volume ls - list available volumes
 
39.        docker volume rm - remove a named volume
 
40.        docker system prune - remove all unused objects from Docker
 
41.        docker system df - show the usage of Docker objects

42.        docker system events - show the events generated by Docker on the system
 
43.         docker system info - show the system-wide information about Docker
 
44.        docker system inspect - show detailed information about Docker objects
 
45.        docker system logs - show the system logs of Docker
